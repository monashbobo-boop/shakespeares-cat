# 活动在 WordPress 后台怎么管理

社里一直在用一张活动表（Notion 导出的 CSV，放在 `data/活动表.csv`）。网站上所有和活动有关的地方都从这张表来：本学期活动页的列表、日历和学期卡，首页「这学期的活动安排」，往期活动页的活动记录和书架。

上线到 WordPress 以后，每场活动就是后台的一条「活动」，字段和这张表的列一一对应。社里习惯在表格里排活动的话，也可以继续在表格里排，再用 WP All Import 之类的插件把同一份 CSV 导进去，列名不用改。

## 一场活动的字段

| 表格的列 | 后台字段类型 | 网站上显示吗 | 说明 |
| --- | --- | --- | --- |
| 活动名称 | 标题 | 显示 | 有书的活动，名称里写《书名》，网站会自动把活动和书连起来 |
| 活动类型 | 下拉选择 | 显示 | 文学夜、线下文学读书会、线上文学深度讨论、嘉宾分享、其他特别活动，以及青少年线上读书会、青少年线下活动 |
| 活动形式 | 下拉选择 | 显示 | 线下、线上、混合 |
| 开始时间 | 日期时间 | 显示日期 | 网站目前只显示日期，时间统一看公众号 |
| 结束时间 | 日期时间 | 不显示 | 留着做日历订阅 |
| 地点 | 文字 | 显示 | Nunawading Community Hub、Zoom，或者具体地址 |
| 合作方 | 文字 | 显示 | 合作的机构或嘉宾，往期活动表里写作「合作方或嘉宾」 |
| 人数上限 | 数字 | 暂不显示 | |
| 报名状态 | 下拉选择 | 暂不显示 | 即将开放、报名中、报名结束 |
| 报名链接 | 链接 | 暂不显示 | 报名仍然统一走公众号 |
| 费用 | 文字 | 暂不显示 | 空着表示免费 |
| 负责人 | 文字 | 显示，写作「主持人」 | |
| 发布状态 | 下拉选择 | 决定显不显示 | 只有「已发布」的活动会出现在网站上，「待审核」的不会 |
| OneDrive文件夹 | 链接 | 不显示 | 社里内部用 |
| 协助成员 | 文字 | 不显示 | 社里内部用 |
| 相关任务 | 关联 | 不显示 | 社里内部用 |

「暂不显示」的字段已经建好，以后想在网站上显示报名链接或费用，只要改页面模板，不用补数据。

## 哪些活动算本学期，哪些算往期

学期按日期范围划分。现在的第三学期是 2026 年 10 月 1 日到 12 月 31 日：这段时间里的活动出现在本学期活动页，之前的都进往期活动。在 WordPress 里，学期是一条「学期」，填名称和起止日期就行，不用一场一场地给活动选学期。

## 往期活动页

- **活动记录**：本学期之前的每一场，按月份分组，新的在前，可以按年份和活动类型筛选。条数和起止月份自动算。
- **书架**：从往期活动里整理出来，活动名称里有《书名》的线下读书会、深度讨论和嘉宾分享都算，观影会不算。同一本书读几次只放一本。
- 书的作者、封面和底色在「书」里填。没有封面就用书名、作者和底色排一个封面。

## 还没进活动表的场次

排期表里已经定下、但还没进活动表的场次，原型里先放在 `data/本学期排期补充.csv`，列名和活动表一样。同一天、名字相近的两条会合并：以活动表为准，活动表空着的格子（比如负责人）用补充表填上。等这些场次进了活动表，把补充表里对应的行删掉就行。上线到 WordPress 以后不需要这个文件。

## 原型里怎么更新

1. 从 Notion 把活动表导出成 CSV，覆盖 `data/活动表.csv`，列名不要改。
2. 运行 `python3 tools/import_events.py`，生成 `assets/js/events-data.js`。
3. 再运行 `python3 tools/build_single.py` 生成单文件原型。

本学期的书（封面、底色）在 `assets/js/main.js` 的 `TERM_BOOKS`，往期书的作者和封面在 `BOOK_INFO`，学期的起止日期在 `TERM`。
