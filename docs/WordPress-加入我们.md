# 「加入我们」页在 WordPress 后台怎么管理

这一页有三块内容在后台管理：三个文件夹（加入方式）、木杆上的挂牌（志愿者岗位）、最下面的加入表单。还有一块「书友的话」，收到真实留言之前不显示。改一条，页面上对应的那一个就跟着变，不用碰设计。

## 加入方式（三个文件夹）

每个文件夹是一条「加入方式」。文件夹正面写标题和一句话，点开后抽出来的那张纸写具体怎么做。

| 字段 | 填什么 | 例子 |
| --- | --- | --- |
| 标题 | 文件夹正面的大字 | 参加一场活动 |
| 一句话 | 文件夹正面的说明，一两句 | 挑一场感兴趣的，联系我们报名。 |
| 文件夹颜色 | 从下拉里选：灰绿、麦黄、雾蓝、米灰、藕粉 | 灰绿 |
| 图标 | 从下拉里选一个手绘图标 | book |
| 纸上的标题 | 抽出来那张纸最上面的一句话，不加逗号，13 个字以内 | 第一次来只要知道这几件事 |
| 纸上的要点 | 每行一条，写成「名称：内容」，名称两到四个字，三到四条最合适 | 报名：看公众号的活动推文，按推文里的方式报名。 |
| 按钮文字（选填） | 纸最下面的文字按钮 | 看本学期活动 |
| 按钮链接（选填） | 按钮跳到哪里 | /events |

「纸上的要点」用一个多行文本框就行，不需要付费插件：

```
报名：看公众号或小红书「莎士比亚的猫文学社」的活动推文，发消息联系我们加入活动群。
地点：线下活动在 Nunawading Community Hub，部分活动在 Zoom 上。
费用：部分活动免费，部分需要分摊场地或茶点费用。
```

网页按每行第一个「：」分成名称和内容。纸的长度跟着内容走，写多了纸会更长，文件夹会往下让出更多位置。

排列顺序用 WordPress 自带的「顺序」字段（页面属性里的 menu order），数字小的在左边。页面按三列排，写成三条最整齐；多于三条会换到下一行。

## 志愿者岗位（挂牌）

每张挂牌是一条「志愿者岗位」。正面写岗位和一句话，点一下翻到背面，一项一行写具体做什么，最下面是怎么报名。现在的六个岗位是社长 2026 年 11 月定的：模块组织、活动执行、活动内容、活动宣传、外部联络、AI 与数字技术。

| 字段 | 填什么 | 例子 |
| --- | --- | --- |
| 岗位名 | 两到六个字 | 活动执行 |
| 一句话 | 挂牌正面，15 个字以内 | 场地布置、接待、秩序维护 |
| 纸色 | 从下拉里选：米白、灰绿、麦黄、雾蓝、砖红、牛皮 | 灰绿 |
| 图标 | 从下拉里选一个手绘图标 | team |
| 具体做什么 | 多行文本，一项一行，三四项最合适 | 场地布置<br>接待<br>秩序维护 |
| 时间（选填） | 填了才显示，正面最下面的红字，背面也会显示 | 每场约 3 小时 |
| 适合谁（选填） | 填了才显示，20 个字以内 | 做事细心，不怕和人打交道 |
| 正在招募 | 勾上才显示。某个岗位招满了，取消勾选就会从木杆上拿下来 | ✓ |

背面的字数有上限，因为挂牌大小固定，写太长会被纸边切掉。电脑上一排最多放 8 张，手机上左右滑动。

六种纸色就是原来那六张标签纸，图片在 `assets/img/tags/paper-1.webp` 到 `paper-6.webp`，主题里固定好，后台只选名字。

## 在 WordPress 里怎么建

和活动、书一样，两样各建一个自定义内容类型（用 ACF 或 Custom Post Type UI 这类插件）：

- 「加入方式」：标题用文章标题，其余是自定义字段；「纸上的要点」用多行文本。
- 「志愿者岗位」：岗位名用文章标题，其余是自定义字段；「具体做什么」用多行文本，「正在招募」用勾选框。
- 「书友的话」：称呼、一句介绍、留言内容、底色。一条都没有的时候，这一段整块不显示。只放征得同意的真实留言。

图标和颜色用下拉选项而不是自由填写，这样谁来改都不会改坏页面的配色。图标可选的名字就是 `assets/img/sketch/` 里的文件名（不带 `-light` 的那一套），比如 book、team、heart、calendar、chat、palette、camera、typewriter、laptop。

## 加入表单

社长要求在这一页加一张报名表，原来的「你可能还想问这些」统一挪到了「关于我们」。表单有四项：称呼、邮箱或微信号、想怎么参与（参加活动、加入微信活动群、做志愿者，可多选）、想说的话（选填），最后勾选同意隐私说明。

WordPress.com 自带表单区块（Jetpack Forms），不用另外装插件：在页面里插入一个表单区块，按上面四项建字段，收到的留言会发到社里的邮箱，也能在后台「反馈」里看到。原型里的表单只做演示，不会真正发送。邮箱地址现在是示例 hello@example.org，上线前换成社里的邮箱。

## 原型里的数据在哪里

`assets/js/main.js` 里的 `JOIN_WAYS`（三个文件夹，`points` 每条是「名称」和「内容」两项）和 `VOL_ROLES`（挂牌，`tasks` 是背面一项一行的具体工作，`time` 和 `fit` 选填）。颜色名对应的色值在 `FOLD_COLORS`，纸色对应的图片在 `PAPERS`。
