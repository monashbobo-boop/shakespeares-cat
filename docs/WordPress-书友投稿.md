# 书友投稿在 WordPress 后台怎么管理

网站上「书友投稿」页和首页的投稿入口，读的都是同一份「投稿」数据。管理员在后台录一篇稿子，下面这些地方会自动更新：

- 首页投稿入口的稿纸：显示「本期刊登」那一篇的开头
- 投稿页上方的稿纸阅读器：显示「本期刊登」那一篇，自动分页，可以翻页
- 投稿页「这些文字已经和大家见过面了」：所有已刊登的稿子，按刊登时间排列，点开任意一篇就在上方的稿纸里读全文
- 投稿页的数字：刊登篇数和作者人数按实际数据算出来

## 一篇投稿要填的字段

| 字段 | 填什么 | 例子 |
| --- | --- | --- |
| 篇名 | 文章标题，不加书名号 | 外婆的腌菜坛 |
| 署名 | 作者希望用的名字，可以是笔名 | 林间 |
| 栏目 | 读后感、散文、诗、小说片段，四选一 | 散文 |
| 刊登学期 | 选一个「学期」 | 2026 年第三学期 |
| 本期刊登 | 勾选后放在投稿页最上面。同一时间只勾一篇 | 勾选 |
| 导语 | 一两句话，说明这篇稿子的来历 | 读完《呼兰河传》那一周…… |
| 编辑手记 | 编辑组的一句短评，以「编辑手记：」开头 | 编辑手记：文章不急着抒情…… |
| 正文 | 直接粘贴全文，段落之间空一行 | |

在 WordPress 里，这是一个自定义内容类型「投稿」，字段用 ACF 之类的插件建，和活动、书、学期、地点放在一起。

## 稿纸每页能放多少字

网站把正文排进方格稿纸，规矩和真的稿纸一样：

- 每页 **15 列 × 10 行，共 150 格**。电脑和手机上一样，所以每一页的字数是固定的。
- 一格一个字，标点也占一格。
- 每段开头空两格。诗的每一行另起一行，段首同样空两格。
- 标点不会出现在一行的开头，会挤进上一行最后一格。
- 一段写完，这一行剩下的格子空着，下一段换行开始。

所以每页实际能放的字数在 **120 到 145 字**之间，段落越多，空格越多，字就越少。一般来说：

| 正文字数 | 大约几页 |
| --- | --- |
| 300 字以内 | 2 至 3 页 |
| 1000 字 | 8 页左右 |
| 3000 字 | 22 页左右 |

字多就自动多分几页，不用手动分页，也不用担心某一页放不下。稿纸下方会显示「第几页，共几页」，标题下面会显示总字数和总页数。

## 不用填的

- 页码和分页：自动算
- 字数：自动算
- 首页和投稿页的摘录：自动取正文开头

## 原型里的数据在哪里

原型里这些数据写在 `assets/js/main.js` 的 `SUBMISSIONS` 里，每一条对应后台的一篇投稿，字段名一一对应：`title` 篇名、`author` 署名、`genre` 栏目、`term` 刊登学期、`featured` 本期刊登、`intro` 导语、`note` 编辑手记、`text` 正文。分页规则在同一个文件的 `MS_COLS`、`MS_ROWS` 和 `msLines()` 里。
