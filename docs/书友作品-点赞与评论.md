# 书友作品的点赞与评论

给社长和技术组的完整说明在 Claude 文档「书友作品的点赞与评论怎么做」里，这里只记上线时要做的技术步骤。

## 评论

- 用 WordPress 自带评论，不装插件。「作品」内容类型要支持评论（注册时 `supports` 里加 `comments`）。
- 后台「设置 → 讨论」：评论必须经人工批准，打开；评论者必须填写姓名和邮箱，打开；用户必须注册并登录才能评论，关闭；含 1 个以上链接的评论进入审核。
- 反垃圾：WordPress.com 所有套餐自带 Akismet，不用另装。
- 留言只公开称呼和内容，邮箱不公开。隐私说明已写进原型的隐私页。

## 点赞

- 不用 WordPress.com 自带的「赞」：读者必须登录 WordPress.com 账号才能点。
- 装一个免登录的点赞插件，例如 Posts Like Dislike，按浏览器记录（Cookie）防重复，用在「作品」类型上。
- WordPress.com 从 2026 年 4 月起所有付费套餐都能装插件，免费版不行。

## 原型里怎么演示的

- 点赞：记在这台设备的浏览器里（localStorage），刷新后还在，不会真正提交。
- 留言：提交后显示「等待审核」，只有自己看得见，刷新就没了，不会真正发送。
- 代码在 `assets/js/main.js` 的 `LIKED`、`REACT`、`COMMENTS` 三段。
