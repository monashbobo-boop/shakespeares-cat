# 书友作品的喜欢与留言

两样都存在文学社自己的 WordPress 数据库里，不放在读者的浏览器里，也不用第三方服务。后台能看到、能管理，换主题也不会丢。

## 留言：WordPress 自带评论

- 留言就是 WordPress 的评论，存在 `wp_comments` 表里，后台「评论」里审核、回复、删除。
- 「作品」内容类型要支持评论（注册时 `supports` 里加 `comments`）。
- 后台「设置 → 讨论」：评论必须经人工批准，打开；评论者必须填写姓名和邮箱，打开；用户必须注册并登录才能评论，关闭；含 1 个以上链接的评论进入审核。
- 读者没登录也能留言，留称呼和邮箱，邮箱不公开。成员登录后留言，会自动记在他的 WordPress 账号下。
- 反垃圾：WordPress.com 自带 Akismet。
- 网页通过 WordPress 自带的接口读写：`GET /wp-json/wp/v2/comments?post=作品编号` 取已通过的留言，`POST /wp-json/wp/v2/comments` 提交新留言。新留言默认「等待审核」，网页上只有留言的人自己看得到这一条，审核通过后大家都能看到。

## 喜欢：`wordpress/sc-likes` 插件

WordPress 没有自带的「喜欢」，WordPress.com 的「赞」又要求读者登录 WordPress.com 账号，所以写了一个很小的插件，代码在 `wordpress/sc-likes/sc-likes.php`。

- 启用时建一张表 `wp_sc_likes`，每一条喜欢是一行：哪一篇、谁、什么时候。
- **谁**：登录的成员按 WordPress 用户记；没登录的读者，插件给浏览器一个随机编号（不含个人信息），只用来避免同一个人重复点。每人每篇只算一次，再点一下取消。
- 每篇的总数同时写进作品的自定义字段 `sc_like_count`。后台「作品」列表多一列「喜欢」，可以按它排序，看哪篇最受欢迎。
- 接口：`GET /wp-json/sc/v1/likes/作品编号` 返回 `{ count, liked }`；`POST` 同一个地址就是点一下或取消。
- 插件在每个页面的 `<head>` 里输出 `window.SC_WP`（接口地址和防伪码），网页的脚本看到它就会走真实接口。

安装：把 `wordpress/sc-likes` 文件夹打成 zip，后台「插件 → 安装插件 → 上传插件」，启用。WordPress.com 要付费套餐才能装插件。如果「作品」类型的名字不是 `work`，改插件开头的 `SC_LIKES_POST_TYPE`。

## 网页这边

- 喜欢的按钮有两个：作品集下面的留言区，和阅读器最后一页下面。点任何一个，两个一起变。
- 主题输出作品数据时，每篇要带上它在 WordPress 里的文章编号（字段名 `wp`），接口靠它找到这一篇。
- 代码在 `assets/js/main.js` 的 `WPAPI`（读写数据）、`LIKES`（喜欢按钮）、`COMMENTS`（留言区）。

## 原型里怎么演示

原型没有 WordPress，`window.SC_WP` 不存在，喜欢和留言只存在这一页的内存里：点喜欢数字会变，留言提交后显示「等待审核」，刷新就没了，也不会真正发送。
