# 本学期活动在 WordPress 后台怎么管理

每学期只录两样东西：活动和书。页面上的学期卡、活动列表、日历、书单、首页的活动卡片，都从这两样自动生成，不用另外写。

## 一场活动要填的字段

和社里的排期表一样，四项必填，一项选填：

| 字段 | 填什么 | 例子 |
| --- | --- | --- |
| 日期 | 活动那天 | 2026-10-31 |
| 名称 | 排期表里的「活动 / 书目」 | 陈忠实《白鹿原》① |
| 类型 | 文学夜、线下文学读书会、青少年线上读书会、青少年线下活动、嘉宾活动 | 线下文学读书会 |
| 主持人 | 主持人的称呼 | Ally |
| 书（选填） | 这场读哪本书，从「书」里选 | 白鹿原 |

同一天可以有两场活动，日历上那一天会多一道红线，点开能看到两场。

日期过了的活动自动显示「已结束」。时间、地点、报名链接不放在网站上，统一看公众号，所以临时调整也不用改网站。

## 一本书要填的字段

| 字段 | 填什么 | 例子 |
| --- | --- | --- |
| 书名 | 不加书名号 | 白鹿原 |
| 作者 | 作者或导演 | 陈忠实 |
| 封面（选填） | 上传一张图，书封、电影海报都可以，竖版最好，大约 2:3 | |
| 底色（选填） | 没有封面时，用书名和这个颜色排一个封面 | |

书单会自动写出这本书在哪几天读、由谁主持，比如「分三次读：10 月 31 日（Ally）、11 月 7 日（Tom）、11 月 14 日（Tony）」。

在 WordPress 里，活动和书各是一个自定义内容类型，活动里的「书」字段是关联字段，用 ACF 之类的插件建。封面用书的「特色图片」就行。

## 原型里的数据在哪里

`assets/js/main.js` 里的 `TERM`（学期名）、`TERM_BOOKS`（书，`cover` 是封面图片地址，空着就用 `c` 底色排封面）和 `EV`（活动）。
