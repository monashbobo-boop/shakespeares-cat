# 本学期活动在 WordPress 后台怎么管理

活动的字段已经改成和社里的活动表一致，见 `WordPress-活动表.md`。这一页只讲本学期页独有的「书」。

## 一本书要填的字段

| 字段 | 填什么 | 例子 |
| --- | --- | --- |
| 书名 | 不加书名号 | 白鹿原 |
| 作者 | 作者或导演 | 陈忠实 |
| 封面（选填） | 上传一张图，书封、电影海报都可以，竖版最好，大约 2:3 | |
| 底色（选填） | 没有封面时，用书名和这个颜色排一个封面 | |

活动和书不用手动关联：活动名称里出现《书名》，网站就把这场活动算在这本书下面。书单会自动写出这本书在哪几天读、由谁主持，比如「分三次读：10 月 31 日（Ally）、11 月 7 日（Tom）、11 月 14 日（Tony）」。

同一天可以有两场活动，日历上那一天会多一道红线，点开能看到两场。日期过了的活动自动显示「已结束」。

页面上原来的「来之前你可能想知道这些」已经删掉，常见问题统一放在「关于我们」，这里只留一句链接。

## 原型里的数据在哪里

`assets/js/main.js` 里的 `TERM`（学期名和起止日期）和 `TERM_BOOKS`（书，`cover` 是封面图片地址，空着就用 `c` 底色排封面）。活动本身来自 `assets/js/events-data.js`，由 `tools/import_events.py` 从活动表生成。
