# 书友作品在 WordPress 后台怎么管理

「书友作品」只收已经在公众号发表过的作品，不在网站上征稿。管理员在后台录一篇，下面这些地方会自动更新：

- **作品集**：每一篇是一个摊开的对页，左页竖排篇名和署名，右页是正文开头一段，其他篇叠在两边。拖动、点两边或者按方向键换一篇
- **翻页阅读器**：点中间那一篇，或者点「翻开来读」，打开一本摊在桌上的书，可以一页一页翻（电脑上看左右两页，手机竖屏一次一页）。也可以切换成「文字版」，字更大，方便放大和读屏
- **在公众号读原文**：阅读器下方，跳到这篇在公众号的原文
- **点赞数和留言**：由 WordPress 自己记录，不用手填，做法见 `书友作品-点赞与评论.md`

## 一篇作品要填的字段

| 字段 | 填什么 | 例子 |
| --- | --- | --- |
| 篇名 | 文章标题，不加书名号 | 落叶 |
| 署名 | 作者希望用的名字，可以是笔名 | 赤夜 |
| 扉页纸色 | 下拉选择：灰绿、麦黄、雾蓝、藕粉、米灰。作品集左页和阅读器封面用这个颜色 | 灰绿 |
| 原文链接 | 这篇在公众号的文章地址 | https://mp.weixin.qq.com/s/…… |
| 栏目（选填） | 散文、小说、读后感等 | |
| 发表日期（选填） | 在公众号发表的日期，用来排序 | 2026-10-20 |
| 正文 | 直接粘贴全文，段落之间空一行 | |

在 WordPress 里，这是一个自定义内容类型「作品」，字段用 ACF 之类的插件建。建这个类型时要勾选支持评论，否则作品下面不会出现留言框。纸色用下拉选项，不要让人自己填颜色，配色就不会被改坏。

## 翻页阅读器怎么排版

不用手动分页，阅读器按版面自动排：

- 宋体正文，每行大约 20 个字，每页大约 15 行；第一页上方留给篇名和署名
- 每段开头空两格，句号逗号这类标点不放在行首，会挂在上一行行尾；引号、书名号的前半个不会留在行尾
- 最后一页正文后面写「（完）」；如果最后一页满了，会多出一页
- 页码自动编；页面下方显示「第几至第几页，共几页」

所以只要保证正文里段落之间空一行就行。英文单词不会被从中间拆开。

三维阅读器用的 three.js 只在第一次打开时下载。浏览器不支持 WebGL 或者下载失败，会直接打开文字版；读者选过文字版，下次也会记住。

## 不用填的

- 页码和分页：自动算
- 作品集里的字数（「约 3600 字」）和开头摘录：自动取正文
- 点赞数和留言：WordPress 记录

## 原型里的数据在哪里

`assets/js/main.js` 的 `WORKS`，每一条对应后台的一篇作品：`title` 篇名、`author` 署名、`paper` 扉页纸色、`url` 原文链接、`text` 正文。`likes` 和 `comments` 上线后不用填。原文链接现在都指向公众号首页，上线时换成每篇文章的地址。

作品集的代码在 `main.js` 的「书友作品集」一段；阅读器是单独的 `assets/js/reader.js`。
