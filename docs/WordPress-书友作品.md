# 书友作品在 WordPress 后台怎么管理

「书友作品」只收已经在公众号发表过的作品，不在网站上征稿。管理员在后台录一篇，下面这些地方会自动更新：

- 作品页上方的稿纸阅读器：默认显示最新发表的一篇，自动分页，可以翻页
- 阅读器旁边的「在公众号读原文」按钮：跳到这篇在公众号的原文
- 作品页「这些作品都在公众号发表过」：所有作品按发表时间排列，新的在前，点开任意一篇就在上方的稿纸里读全文
- 每篇的点赞数和留言：由 WordPress 自己记录，不用手填，做法见 `书友作品-点赞与评论.md`

## 一篇作品要填的字段

| 字段 | 填什么 | 例子 |
| --- | --- | --- |
| 篇名 | 文章标题，不加书名号 | 外婆的腌菜坛 |
| 署名 | 作者希望用的名字，可以是笔名 | 林间 |
| 栏目 | 读后感、散文、诗、小说片段，四选一 | 散文 |
| 发表日期 | 在公众号发表的日期，用来排序 | 2026-10-20 |
| 原文链接 | 这篇在公众号的文章地址 | https://mp.weixin.qq.com/s/…… |
| 导语 | 选填，一两句话，说明这篇的来历 | 读完《呼兰河传》那一周…… |
| 编辑手记 | 选填，一句短评，以「编辑手记：」开头 | 编辑手记：文章不急着抒情…… |
| 正文 | 直接粘贴全文，段落之间空一行 | |

在 WordPress 里，这是一个自定义内容类型「作品」，字段用 ACF 之类的插件建，和活动、书、学期、地点放在一起。建这个类型时要勾选支持评论，否则作品下面不会出现留言框。

## 稿纸每页能放多少字

网站把正文排进方格稿纸，规矩和真的稿纸一样：

- 每页 **15 列 × 10 行，共 150 格**。电脑和手机上一样，所以每一页的字数是固定的。
- 一格一个字，标点也占一格。
- 每段开头空两格。诗的每一行另起一行，段首同样空两格。
- 标点不会出现在一行的开头，会挤进上一行最后一格。
- 一段写完，这一行剩下的格子空着，下一段换行开始。

所以每页实际能放的字数在 **120 到 145 字**之间，段落越多，空格越多，字就越少。一般来说：

| 正文字数 | 大约几页 |
| --- | --- |
| 300 字以内 | 2 至 3 页 |
| 1000 字 | 8 页左右 |
| 3000 字 | 22 页左右 |

字多就自动多分几页，不用手动分页，也不用担心某一页放不下。稿纸下方会显示「第几页，共几页」，标题下面会显示总字数和总页数。

## 不用填的

- 页码和分页：自动算
- 字数：自动算
- 作品列表里的摘录：自动取正文开头
- 点赞数和留言：WordPress 记录

## 原型里的数据在哪里

原型里这些数据写在 `assets/js/main.js` 的 `WORKS` 里，每一条对应后台的一篇作品，字段名一一对应：`title` 篇名、`author` 署名、`genre` 栏目、`date` 发表日期、`url` 原文链接、`intro` 导语、`note` 编辑手记、`text` 正文。`likes` 和 `comments` 是原型里的示例点赞数和留言，上线后不用填。原文链接现在都指向公众号首页，是示例。分页规则在同一个文件的 `MS_COLS`、`MS_ROWS` 和 `msLines()` 里。
