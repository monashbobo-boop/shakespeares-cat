# 这个项目用到的设计 skill

Claude Code 在这个仓库里工作时会自动加载这里的 skill。

| 文件夹 | 来源 | 版本 | 授权 |
| --- | --- | --- | --- |
| `design-taste-frontend/` | https://github.com/Leonxlnx/taste-skill （`skills/taste-skill`） | tasteskill 2.5.1，提交 f6b7657 | MIT |
| `impeccable/` | https://github.com/pbakaus/impeccable （`.claude/skills/impeccable`） | 4.8.2，提交 b4bff16 | Apache 2.0 |

两个都是原样复制，没有改动，授权文件放在各自的文件夹里。

在这个项目里用的时候，网站自己的规则优先：标题一句话不加逗号、不用「xx · xx」、按钮只有文字不带箭头、不用分隔线、配色只用 style.css 开头的颜色。taste skill 自带的照片、场景和 3D 素材是给公司官网准备的，文学社网站不用。
